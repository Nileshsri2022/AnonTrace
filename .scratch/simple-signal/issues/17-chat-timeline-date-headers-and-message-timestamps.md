## 1. Context & User Story
When communicating across multiple days or checking historical messages, users need chronological clarity similar to WhatsApp and Signal. Currently, `ChatScreen` renders raw message bubbles with no date dividers and no time stamps, making it difficult to distinguish recent messages from historical messages.

---

## 2. Technical Scope

### 2.1 Timeline Data Structures
Define typed models for timeline rendering:
```dart
sealed class TimelineItem {}

class DateHeaderItem extends TimelineItem {
  final DateTime date;
  DateHeaderItem(this.date);
}

class MessageBubbleItem extends TimelineItem {
  final MessageSummary message;
  MessageBubbleItem(this.message);
}
```

### 2.2 Timeline Grouping Adapter
Implement a pure, testable helper function:
```dart
List<TimelineItem> groupMessagesByDate(List<MessageSummary> messages);
```
- Iterates chronological messages.
- Whenever a message is on a new calendar date compared to the previous message (or for the very first message), injects a `DateHeaderItem`.
- Encapsulates date label formatting:
  - Same calendar day as `now` -> "Today"
  - Calendar day before `now` -> "Yesterday"
  - Older dates -> "d MMMM yyyy" (e.g., "24 October 2026")

### 2.3 Bubble Timestamp Formatting
Within each message bubble, format `message.createdAt` (or current timestamp if 0) into 12-hour format:
```dart
String formatMessageTime(int timestampMs); // e.g. "05:42 PM"
```
Place the timestamp subtly at the bottom-right of each incoming and outgoing bubble with appropriate contrast and padding.

### 2.4 ChatScreen Integration
- Update `ChatScreen`'s `ListView.builder` to consume `List<TimelineItem>` generated by `groupMessagesByDate(_messages)`.
- Render `DateHeaderChip` for `DateHeaderItem` with centered pill styling (rounded border, subdued background color).
- Render `_buildMessageBubble` for `MessageBubbleItem` displaying bubble text and bottom-right timestamp.
