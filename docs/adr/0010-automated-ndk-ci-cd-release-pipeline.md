# Automated Multi-Arch Android NDK Compilation and Tag-Driven Releases

We decided to automate the complete Android APK build and publication pipeline via GitHub Actions, compiling `simple-signal-core` across `arm64-v8a`, `armeabi-v7a`, and `x86_64` using `cargo-ndk`, bundling the resulting `jniLibs` into the Flutter release APK, and publishing dual-signed (`v1+v2`) release artifacts strictly on version tag pushes (`v*`). Manually cross-compiling native C/Rust libraries for mobile targets is error-prone, prone to ABI mismatches, and difficult to verify across diverse physical handset architectures. Centralizing multi-arch compilation, locked dependency validation (`cargo test --locked`), and release publishing in CI ensures tamper-resistant, reproducible APK builds for all users.
