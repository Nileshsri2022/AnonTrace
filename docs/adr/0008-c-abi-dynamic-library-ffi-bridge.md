# C-ABI Dynamic Library FFI Bridge with JSON Serialization

We decided to implement the Flutter-to-Rust bridge using a direct, standard C-ABI dynamic library layer (`dart:ffi` with `extern "C"` functions returning JSON strings) rather than heavy automated code-generation frameworks like `flutter_rust_bridge`. While codegen frameworks generate typed Dart wrappers, their code-generation build steps frequently introduce fragile toolchain dependencies, compile-time panics on cross-compilation targets (`cargo-ndk`), and complex ABI synchronization requirements across multiple architectures. A minimal, explicit C-ABI with JSON serialization guarantees zero-overhead stability across all Android NDK ABIs (`arm64-v8a`, `armeabi-v7a`, `x86_64`) and desktop operating systems with deterministic error recovery.
