# Swipe-to-Reply and Quoted Message Encapsulation

We decided to support contextual message replies in `ChatScreen` using in-band quoted message encapsulation (`[QUOTE:snippet]\ntext`) paired with a persistent reply preview banner and swipe/long-press gestures. In active peer-to-peer discussions, referring to specific historical messages is essential to avoid ambiguity. Because `simple-signal-core` encrypts arbitrary UTF-8 byte payloads through the Double Ratchet state machine with ML-KEM-1024 and AES-256-GCM, embedding quoted snippets directly within the plaintext payload requires zero schema migrations in SQLite, introduces zero out-of-band wire metadata, and guarantees that quote contents remain strictly end-to-end encrypted between conversational peers without exposing reference IDs or quote previews to network relays.
