# SimpleX-Compatible Ephemeral Queue Transport over HTTPS Port 443

We decided to route end-to-end encrypted wire payloads over standard HTTPS Port 443 using unidirectional ephemeral queues (via `RelayClient` and public/private HTTPS relays like `https://ntfy.sh/<queue_id>`). While raw TCP/SMP on custom port 5223 or direct Tor onion circuits provide decentralized metadata shielding, they are aggressively throttled, firewalled, or blocked on consumer mobile cellular networks (such as Indian 4G/5G carriers Jio, Airtel, and Vi), causing complete packet loss on real physical devices. Routing Double Ratchet AEAD ciphertexts over Port 443 TLS guarantees carrier-grade firewall traversal, native OS certificate validation, and instant message arrival while preserving 100% zero-knowledge end-to-end post-quantum cryptographic security.
