# Long-Press Message Actions and Local Message Deletion

We decided to implement contextual long-press message actions in `ChatScreen` offering clipboard copying and atomic local message deletion (`simple_signal_delete_message`), exposing a dedicated C-ABI endpoint from `simple-signal-core` down to SQLite encrypted storage. In anonymous, metadata-free messaging systems, users require the ability to purge sensitive plaintext messages locally from their device ("Delete for Me") without generating traffic-analysis traces or network packets to the relay or peer. Executing message deletion strictly within local storage preserves the integrity of active Double Ratchet cryptographic states, generates zero network packets over the HTTPS Port 443 relay, and ensures that sensitive messages can be cleared from RAM and encrypted storage on demand.
