# Chat Timeline Date Headers and Message Timestamps

We decided to introduce a client-side Timeline Grouping Adapter into the `ChatScreen` presentation layer that partitions raw linear message collections into chronological segments separated by centered Date Header Chips ("Today", "Yesterday", or formatted calendar date strings) and enhances individual message bubbles with localized 12-hour timestamps (`hh:mm a`). The current user interface rendered continuous lists of undated text bubbles, which deprived users of chronological context during multi-day conversations and deviated from standard messaging UX expectations (such as WhatsApp and Signal). Transforming message timelines strictly on the client device using local SQLite timestamps requires zero modifications to the Post-Quantum Double Ratchet cryptographic core, introduces zero wire protocol headers, produces zero metadata leakage across the HTTPS Port 443 relay, and provides a polished, familiar timeline representation while preserving 100% Zero-Knowledge privacy.
