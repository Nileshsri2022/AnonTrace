# Scroll-to-Bottom Floating Action Button and Unread Counter

We decided to introduce a Scroll-to-Bottom Floating Action Button (FAB) equipped with a dynamic unread message badge into `ChatScreen`. When users scroll backwards through message history during an active conversation, incoming Server-Sent Events (SSE) messages can arrive without entering the immediate viewport. The Scroll-to-Bottom FAB automatically appears whenever the scroll offset departs from the conversation bottom, accumulates an unread count badge as new messages are decrypted in the background, and animates smoothly back to the live message frontier upon single tap, resetting the unread badge. This enhancement is entirely contained within the client viewport presentation layer, requiring zero wire protocol alterations, generating zero network telemetry, and maintaining 100% Zero-Knowledge post-quantum privacy.
